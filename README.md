# Vortex

Modded Twitch client for Android by Alcatru.

## Download

Get the latest APK from the [Releases](https://github.com/Alcatru/vortex-releases/releases/latest) page.

## Install

1. Download the `.apk` from the latest release
2. Allow installation from unknown sources on your device
3. If Play Protect blocks it, tap "More details" → "Install anyway"

Updating: install the new APK over the old one, your settings and login are kept.
Inside the app, *Vortex settings → Mises à jour → Vérifier les mises à jour* checks this page for a newer version.

## Features

- Third-party emotes (BTTV, FFZ, 7TV)
- Ad blocking
- Chat enhancements (highlights, spam filter, chat history)
- Live rewind without leaving the live screen
- Live notifications for followed channels with the bell on
- Player tweaks (VOD speed, VOD sync, chapters) and gesture controls

## Requirements

- Android 5.0+ (API 21)
- arm64-v8a device (most modern Android phones)
